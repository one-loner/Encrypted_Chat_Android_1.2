# Проверка поставляемой сборки

Дата: 13 октября 2026.

- `assembleDebug` — успешно; создан устанавливаемый debug APK.
- `assembleDebugAndroidTest` — успешно.
- `apksigner verify --min-sdk-version 24` — подпись APK v2 корректна.
- Проверка интерфейса в эмуляторе: первый запуск, установка пароля, генерация
  именованного ключа, отображение QR и запрос пароля после возврата из фона — успешно.
- `testDebugUnitTest` — **11 тестов, 0 ошибок** (CryptoTest: 7; ChatApiTest: 4).
- `lintDebug` — **0 ошибок**, 4 предупреждения GradleDependency о более новых
  версиях ViewPager и тестовых библиотек. Функциональных ошибок/API-несовместимостей
  Android Lint не обнаружил.
- На эмуляторе **Android 15 / API 35, arm64-v8a**:
  `VaultDeviceTest` — **4 теста, 0 ошибок**, реальный Android Keystore.
  Запуск выполнен через `adb shell am instrument -w
  com.loner.encryptedchat.test/androidx.test.runner.AndroidJUnitRunner`.
  Gradle `connectedDebugAndroidTest` столкнулся с TLS-сбоем при загрузке UTP;
  этот сбой обойдён прямым запуском того же тестового APK.

Проверены независимые криптографические векторы PBKDF2/AES-GCM, Unicode,
целостность резервных копий, отказ при неверном пароле, раздельные PHP-сеансы,
CSRF, кэширование зашифрованных файлов, обработка отзыва сессии, реальное
зашифрованное хранилище, блокировка, смена пароля и перенос данных с другим
локальным паролем.

Серверный протокол проверен по исходникам коммита
`63c5cce3abfae81ebd42a9e46df8695fba0ef087` и через MockWebServer.
Подключение к реально развёрнутому серверу пользователя не проверялось:
его HTTPS-адрес и учётные данные не предоставлены.

Минимальная версия приложения — **API 24**. Статическая проверка совместимости
прошла; запуск на физическом устройстве Android 7.0/API 24 не выполнялся.
QR-сканирование реальной камерой, обмен с веб-клиентом и одновременная работа
нескольких чатов на развёрнутом сервере требуют приёмки с реальными устройствами
и сервером. Сценарий приёмки приведён в README.md.

Машиночитаемые отчёты тестов и текст Android Lint приложены в `validation/`.
